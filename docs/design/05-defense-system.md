*Status: skeleton. Blocking: D-3 (enemy identity) before content; M4 planning.*

## Thesis: gradient engineering (P-10)
Waves are emergent trail-followers, so towers act on the *field*, not only on targets:
repellent towers write negative scent, lures write attractants, and the strategic game is
sculpting the landscape pests navigate. Damage towers exist, but the maze is chemical.
Continuous with phase-2 counterplay (wash/stomp/dig — the player has been doing gradient
engineering by hand since phase 2).
