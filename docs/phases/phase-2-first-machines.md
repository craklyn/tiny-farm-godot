# Phase 2 — First Machines

*Stub. Detailed design starts at milestone M3 planning.*

**Boundary flag (Q-79, 2026-09-01):** the designer's progression framing runs phase 1
all the way to the first automatic tower, which would fold this stub's content into
`phase-1-homestead.md` (where the straw-man progression skeleton now sequences it) and
renumber the later phases. Content here stays valid either way; the label is what's open.

**Premise:** Simple automation (sprinklers first) begins retiring phase-1 labor. Pests now
arrive in groups; the player faces a variety of minor combat challenges. Gate to phase 3:
sustained farm yield achieved by repelling enough pests (P-4).

**Design intent:** This is the proof-of-concept for the delegation arc — the first time
the player watches a machine do their old job. It should feel *earned* and slightly
magical. Combat is introduced gently: the verbs stay tap-commands (S-3), not twitch.

**Group pests are trail dynamics (P-10).** Raids coordinate via pheromone trails on the
scent layer: scouts mark, foragers follow, success reinforces, time decays. Coordination
— not bigger spawn counts — is what makes phase-2 pests different from phase 1's
individuals. Counterplay uses verbs the player already has, with zero new UI: wash trails
with the watering can, stomp scouts before they report back, dig trail breaks with the
hoe. Kid-legible by construction.

**Open questions (settle at M3 planning):**
- Sprinkler acquisition: crafted, bought, or milestone-granted? What resource loop feeds it?
- Trail tuning: decay/reinforcement constants that make raids *readable* (the player
  should be able to see a raid forming and intervene) — and when/how the scent overlay
  (P-10/D-4) is introduced to the player.
- Where do nests sit relative to the farm, and are they visible this early
  (foreshadowing phase 5's trail-tracking)?
- Beyond trail counterplay: any other "minor combat challenges" — swat/chase verbs,
  thrown objects, a dog?
- How does yield-threshold progress get communicated without spreadsheet UI?
- Which phase-1 chores must *never* be automated here, so the player still has hands-on
  work until phase 4?
