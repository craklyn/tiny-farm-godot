# v0.2.1 release-note evidence

This record checks the candidate release notes against `v0.2.0.1..b7d07f9`, the local
`origin/main` tip reviewed on 2026-10-08. It is not player-facing copy.

## Barn finding

The unlockable barn is not a player-accessible addition in this build. Do not add it to
the release notes.

- There is no barn purchase, placement, or entry flow in the live game.
- The live input map contains only the home, chicken coop, and Spiral Tower as structures
  a player can open (`systems/action_router.gd`). It has no barn route.
- The renderer has no barn object. Its cow comment states that no live-game route spawns
  a cow; cows exist only for the Zoo and integration tests (`world/farm.gd`).
- Barn simulation, save, replay, cow movement, and placeholder art landed in
  `6757c1f`, `d8f66ca`, `8612fc6`, `b7d07f9`, and `3b6bb20`. Those commits do not add a
  player purchase, placement, entry, cow source, or finished cow art.

The reviewer finding therefore describes implemented simulation rather than a feature a
player can reach. The draft correctly excludes the barn, cows, milk, and cheese.
