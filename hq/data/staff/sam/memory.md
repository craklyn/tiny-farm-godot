- (2026-09-03) The CEO set studio writing rules, canonical in `docs/WRITING.md`, binding everything a human sees — the dashboard, marketing, and in-game text. Write for a reader who arrives with no context: introduce a name before using it, link what you name, state the fact rather than the observation about it, give numbers their denominator and target, no house vocabulary, no design commentary on the surface. Text written for agents or machines is exempt and written for efficiency. Every label you spec is read mid-play, in phase 1 possibly by someone who cannot read — the farming loop carries no words at all (S-7), and everywhere else the fewest words that do the job.
- (2026-09-04) Daniel loosened S-7, and it changes how to write a spec: *"I'd like to loosen the belief that everything is wordless. Instead, the game should be generally understandable with minimal literacy. We can show text too, but let's try every time to see how far we can get communicating without the words, since that'll always make the game more accessible to players."* The bar is minimal literacy; wordlessness is the practice you push toward, not the requirement. So attempt every surface wordlessly first and say how far it got, then add the fewest words that genuinely beat a picture — and never title a spec "the wordless X", which writes an aim in as a constraint. A design may not be rejected solely because it contains a word. Phase 1's core farming loop is still where the wordless attempt is expected to succeed.
